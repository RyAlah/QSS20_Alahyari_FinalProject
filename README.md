## Code

### [`00_data_cleanup.ipynb`](code/00_data_cleanup.ipynb)

**Purpose:** Clean and standardize all raw datasets for merging.

**Key libraries:** `pandas`, `numpy`, `re`

**Inputs:**
- [`DECENNIALDP2020.DP1...csv`](data/DECENNIALDP2020.DP1-2026-05-14T152641(2).csv) — 2020 Census race data
- [`DECENNIALSF12010.P9...csv`](<data/DECENNIALSF12010.P9-2026-05-19T020157 (2010).csv>) — 2010 Census race data
- [`ACSST5Y2020.S1903-Data.csv`](data/ACSST5Y2020.S1903-Data.csv) — 2020 median income
- [`ACSST5Y2010.S1903...csv`](data/ACSST5Y2010.S1903-2026-06-01T055927.csv) — 2010 median income
- [`ACSDT5Y2020.B25064...csv`](data/ACSDT5Y2020.B25064-2026-06-02T234432.csv) — 2020 median rent
- [`ACSDT5YSPT2010.B25064...csv`](data/ACSDT5YSPT2010.B25064-2026-06-02T234451.csv) — 2010 median rent
- [`ACSDT5Y2020.B25077...csv`](data/ACSDT5Y2020.B25077-2026-06-02T234543.csv) — 2020 home values
- [`ACSDT5Y2010.B25077...csv`](data/ACSDT5Y2010.B25077-2026-06-02T234558.csv) — 2010 home values

**What it does:**

*Helper functions defined:*
- `transpose_reset(df)` — transposes datasets (tracts were originally in columns), resets index, sets column names from row 0
- `transform_ACS_df(df)` — wraps `transpose_reset`, renames the tract column, filters to estimate rows only, extracts `tract_num` as float
- `race_percentages(df, ...)` — calculates `white_pct`, `black_pct`, `asian_pct`, `other_pct`, `hispanic_pct` from raw counts

*2020 Census race data (`df2020`):*
- Transposes and filters to Count rows only (drops Percent rows)
- Cleans column names with regex (removes `\xa0` characters), tags duplicate column names with numeric suffixes
- Extracts columns for total population, White (non-Hispanic), Black (non-Hispanic), Asian (non-Hispanic), Some Other Race (non-Hispanic), and Hispanic (any race)
- Converts string values to floats, calculates racial percentage columns
- Manually codes `near_hblr` and `near_path` boolean columns by checking tract identifiers against a hardcoded list of tracts within ~500m walking distance of each system's stations

*2010 Census race data (`df2010`):*
- Same transpose/clean/convert pipeline; simpler since it has only count rows
- Calculates racial percentage columns from counts
- Manually codes `near_hblr` and `near_path` boolean columns (slightly different tract identifiers from 2020)

*ACS datasets (income, rent, home value — 2010 and 2020):*
- `transform_ACS_df` applied to rent and home value datasets
- Income data cleaned separately (filters to median income estimate rows, renames columns, converts to float)
- Household count (`household_num`) retained from 2020 income data for use as merge weight in `01_data_merge.ipynb`

**Outputs:**
- [`data/2020cleaned1.csv`](data/2020cleaned1.csv) — cleaned 2020 race data with `near_hblr`, `near_path`, racial % columns
- [`data/2010cleaned1.csv`](data/2010cleaned1.csv) — cleaned 2010 race data with `near_hblr`, `near_path`, racial % columns
- [`data/2020income.csv`](data/2020income.csv) — cleaned 2020 median income + household count
- [`data/2010income.csv`](data/2010income.csv) — cleaned 2010 median income
- [`data/2020rent.csv`](data/2020rent.csv) — cleaned 2020 median gross rent
- [`data/2010rent.csv`](data/2010rent.csv) — cleaned 2010 median gross rent
- [`data/2020housing.csv`](data/2020housing.csv) — cleaned 2020 median home value
- [`data/2010housing.csv`](data/2010housing.csv) — cleaned 2010 median home value

### [`01_data_merge.ipynb`](code/01_data_merge.ipynb)

**Purpose:** Aggregate 2020 tracts to match 2010 tract boundaries, merge all datasets, and compute change variables.

**Key libraries:** `pandas`, `numpy`, `re`

**Inputs:**
- All eight cleaned CSVs from `00_data_cleanup.ipynb`

**What it does:**

*Helper functions defined:*
- `add_tract_num(df)` — extracts a float `tract_num` from the census tract string column using regex
- `get_match_key(tract)` — maps 2020 tract numbers to their 2010 equivalents (some 2010 tracts were split in 2020; function collapses children back to the integer parent); includes a `manual_map` for edge cases where the standard rule fails
- `aggregate_race(df, count_cols, bool_cols)` — applies `get_match_key`, sums count columns within each matched group, uses logical OR to aggregate boolean columns (`near_hblr`, `near_path`)
- `aggregate_ACS(df, value_col, weight_col)` — applies `get_match_key`, computes household-weighted average of tract medians when combining split tracts
- `categorize(row)` — assigns each tract one of four `train_access` values: `hblr_only`, `path_only`, `near_both`, `near_neither`

*Processing steps:*
- Adds `tract_num` to all datasets via `add_tract_num`
- Aggregates 2020 race data from 183 tracts → 166 tracts to match 2010 boundaries using `aggregate_race`; recalculates racial percentages from aggregated counts
- Drops tract 9801 (uninhabited special-use tract with null household count)
- Merges `household_num` from 2020 income into 2020 rent and home value datasets to enable weighted aggregation
- Aggregates 2020 income, rent, and home value using household-weighted medians via `aggregate_ACS`
- Merges all datasets (2010 race, 2020 race, 2020 income, 2020 rent, 2020 home value, 2010 home value, 2010 income, 2010 rent) on `tract_num` via sequential left merges into `dfmerged` (166 tracts × 49 columns)
- Creates `train_access` column via `categorize`
- Creates racial percentage point change columns (`white_pct_change`, `black_pct_change`, etc.) by subtracting 2010 percentages from 2020 percentages

**Output:**
- [`data/hudsonmerged.csv`](data/hudsonmerged.csv) — fully merged dataset, 166 tracts, all demographic, economic, and transit variables

### [`02_data_plotvis.ipynb`](code/02_data_plotvis.ipynb)

**Purpose:** Produce all visualizations and run OLS regression and mediation analyses.

**Key libraries:** `pandas`, `numpy`, `matplotlib`, `seaborn`, `statsmodels`, `geopandas`, `shapely`

**Input:**
- [`data/hudsonmerged.csv`](data/hudsonmerged.csv)
- [`data/tl_2010_34017_tract10.shp`](data/tl_2010_34017_tract10.shp) — tract boundaries
- [`data/Light_Rail_Lines_of_NJ_Transit.shp`](data/Light_Rail_Lines_of_NJ_Transit.shp) — HBLR geometry
- [`data/Path_Rail_Line.shp`](data/Path_Rail_Line.shp) — PATH geometry

**What it does:**

*Figure 1 — Bar chart:*
- Groups `dfmerged` by `train_access`, takes mean of each racial `_pct_change` column
- Melts to long format and plots a grouped seaborn bar chart

*Figure 2 — Choropleth maps:*
- Merges `dfmerged` onto the 2010 TIGER shapefile on `tract_num`
- Reprojects HBLR and PATH shapefiles to match tract CRS
- Plots one `RdBu` choropleth per race, overlays HBLR (green) and PATH (blue) lines, clips to Hudson County bounding box

*Distance to CBD control variable:*
- Sets CBD coordinates to Downtown Jersey City (`-74.0431, 40.7178`)
- Projects tracts to EPSG:3424 (NJ State Plane, feet), computes centroid distance to CBD point, converts to miles
- Merges `dist_to_cbd_miles` back into `dfmerged`

*OLS regression:*
- Sets `train_access` as a Categorical with `near_neither` as the reference level
- Fits five separate OLS models (one per race): `{race}_pct_change ~ C(train_access) + median_income_2010 + dist_to_cbd_miles`

*Mediation analysis:*
- Adjusts 2010 income, rent, and home value to 2020 dollars using CPI ratio (2020 CPI / 2010 CPI ≈ 1.187)
- Computes `income_change`, `rent_change`, `home_value_change` as 2020 minus inflation-adjusted 2010 values
- For each of the three mediators, re-runs the five OLS regressions with and without the mediator as an additional control; records coefficients, p-values, and % change in coefficient magnitude
